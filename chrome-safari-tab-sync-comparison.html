Why this product exists

iCloud Tabs and Chrome Sync are useful when your devices stay inside one vendor’s workflow. Saved-session tools are useful when you want to store a group of pages for later. TabSyncBridge is for the gap between those use cases: you want to use Safari on iPhone and a Chromium browser on a computer, while keeping the core tab workflow between devices you control on the same private local network.

  • Mixed-browser workflow: iPhone Safari alongside Chrome, Edge, Brave, Opera, Vivaldi, or another compatible Chromium browser.
  • Local-first connection: the core sync loop is designed for your own private Wi-Fi or local network.
  • Useful remote context: view readable tab titles instead of manually sending links to yourself.
  • Selected remote actions: send close requests to the browser profile that owns the selected tab.

When TabSyncBridge is not the right fit

Use iCloud Tabs if you mainly use Safari across Apple devices. Use Chrome Sync if you mainly use Chrome and want Google’s integrated cross-device workflow. Use a session manager if your priority is saving named tab groups for later rather than seeing live tabs from linked devices.

Start with the setup guide

  1. Install TabSyncBridge on your iPhone.
  2. Install the Safari extension or Chromium companion for the browser workflow you use.
  3. Install the desktop bridge when Chromium native messaging is required.
  4. Keep the devices on the same private Wi-Fi or local network.
  5. Pair once, then use the shared remote tab list.
